# Notes UI kit

A click-through recreation of Student Eco's **Notlar** module — the PDF-sharing screens described in `docs/05-frontend-pages.md`.

**Screens included:** list with filter bar, note detail with download CTA, new-note upload form.

**Components in `app.jsx`:**
- `NoteCard` — list row with course/semester badges
- `NotesList` — page with filter bar
- `NoteDetail` — full detail view
- `NoteUpload` — PDF upload form
- `NotesApp` — view switcher

Open `index.html` to see the interactive prototype. Module accent color is **blue** (`--notes`).
