# Marketplace UI kit

Click-through recreation of Student Eco's **Pazaryeri** module.

**Screens:** listing grid, listing detail with image gallery, scoped message thread, new listing form.

**Components in `app.jsx`:**
- `ListingCard` / `ListingGrid` — image-first cards
- `ListingDetail` — gallery + price + seller + "Satıcıya mesaj"
- `MessageThread` — listing-scoped DM
- `NewListing` — full create flow

Module accent: **orange** (`--market`). Runs without backend.
